# vim notes

| Key | Does |
|---|---|
| `vim file` | open |
| `/word` + Enter | search (`n` = next) |
| `:42` | go to line 42 (nginx -t gives line numbers) |
| `i` | insert (start typing) |
| `A` | jump to end of line + insert |
| `Esc` | stop typing |
| `x` / `dd` | delete char / delete line |
| `u` | undo |
| `:wq` | save + quit |
| `:q!` | quit WITHOUT saving (panic btn) |

if stuck: `:q!` then `nano file` (Ctrl+0 save, Ctrl+X exit).
